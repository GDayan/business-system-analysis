# Запуск доставки для кофейни

## Контекст проекта

Небольшая сеть из трёх кофеен в Минске. Заказы принимаются только на месте и по телефону, часть клиентов уходит к конкурентам с доставкой. Владелец хочет запустить собственную доставку через сайт и мобильное приложение, с интеграцией в кассовую систему (POS) и курьерами в штате.

Цифры в документах условные.
